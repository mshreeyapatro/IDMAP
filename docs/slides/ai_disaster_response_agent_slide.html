🤖 AI Disaster Response & Advisory Agent

Evidence-Grounded Tactical Decision Support via Retrieval-Augmented Generation (RAG)

⚠️ The Operational Challenge

Generic LLMs (like standard ChatGPT) hallucinate inaccurate protocols and lack institutional accountability during cyclone emergencies.

Our Engineering Solution:

A specialized tactical agent that binds real-time numerical predictions directly to legal SOP manuals.

Primary Beneficiaries: State EOC, District Collectors, NDRF/ODRAF Command
⚙️ RAG Pipeline Architecture
1
Vector Knowledge Index:

Chroma DB indexes official IMD SOPs, OSDMA manuals, and NDMA guidelines with 384-D embeddings (all-MiniLM-L6-v2).

2
Dynamic Context Binding:

Injects live eye coordinates, wind velocity, landfall ETA, evacuation quotas, and shelter limits.

3
Traceable Generation:

Synthesizes tactical directives where every sentence is anchored by exact SOP chapter and page citations.

Zero Unanchored Hallucination
🛡️ Key Differentiators
  • ✓
    Deterministic Guardrails: Strict system prompts reject arbitrary suggestions outside government disaster doctrine.
  • ✓
    Closed-Loop SFT / DPO Alignment: Captures operator ratings (1–5) and edits into JSONL datasets for automated continuous model retraining.
  • ✓
    1-Click Executive PDF: Exports complete statewide emergency orders with zero manual data re-entry.
